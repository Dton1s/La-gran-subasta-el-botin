# La gran subasta: El botín

Juego web de subastas por rondas construido con React, TypeScript y Vite.

## Desarrollo local

Requiere Node.js compatible con Vite 8.

```bash
npm ci
npm run dev
```

Para generar una compilación de producción:

```bash
npm run build
npm run preview
```

El progreso de juego y la colección se guardan localmente en el navegador. La versión actual es una experiencia local/offline; el modo online aún no está conectado a un servidor.

## Assets

El repositorio incluye solo los assets cargados por la aplicación (avatares, emotes, insignias de rango, audio e interfaz). Se conservan sus licencias y archivos de atribución disponibles junto a cada paquete. No incluye paquetes de diseño, versiones antiguas, archivos comprimidos ni assets sin referencias en el código.
