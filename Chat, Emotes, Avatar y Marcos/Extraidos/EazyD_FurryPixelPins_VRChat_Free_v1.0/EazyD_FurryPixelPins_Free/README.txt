EazyD Studio - Furry Pixel Pins for VRChat (Free) v1.0
10 original pixel-art pins with gold enamel rim. 32x32 native + 256x256 (nearest-neighbor) PNGs.

Unity: select the textures -> Filter Mode: Point (no filter), Compression: None, Alpha Is Transparency on.
Use them as Expression Menu icons, badge/pin textures on your avatar, or UI sprites.
